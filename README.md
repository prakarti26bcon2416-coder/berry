# Prakarti Sharma &bull; Bougainvillea Pastel Portfolio

A colorful, bougainvillea-themed personal portfolio website for **Prakarti Sharma**, a first-year B.Tech Computer Science & Engineering student at **JECRC University, Jaipur**.

---

## 🌸 Aesthetics: Bougainvillea Coded & Colorful Pastels (Uncrowded)

Designed with inspiration from the cascading bougainvillea vines of Jaipur courtyards, focusing on clean visual breathing room and a colorful pastel harmony:

- **Colorful Pastel Palette**:
  - **Pastel Bougainvillea Rose / Magenta** (`#dc5877`, `#fdedf1`)
  - **Pastel Coral Peach** (`#ea7a52`, `#fef0ea`)
  - **Pastel Golden Apricot** (`#e29739`, `#fef5e8`)
  - **Pastel Leaf Sage / Mint** (`#5e9575`, `#eef6f1`)
  - **Pastel Sky Blue** (`#508bc0`, `#edf4fa`)
  - **Pastel Wisteria / Lilac** (`#8a67ab`, `#f3eef8`)
  - **Sunlit Alabaster Canvas** (`#fffdfa`)
- **Uncrowded, Airy & Breathable Layout**:
  - Clean margins, generous whitespace, and minimal distractions.
  - Delicate bougainvillea vine illustrations and gently drifting papery petal animations.
  - Elegant typography pairing: ethereal floral serif (`Cormorant Garamond`) with modern readable sans-serif (`Plus Jakarta Sans`).
- **Smooth & Responsive**:
  - Tested across mobile smartphones, tablets, and widescreen desktop displays.
  - 1-click email copy to clipboard with instant feedback.
  - Interactive message form that drafts a pre-formatted email to Prakarti's university Gmail address.
